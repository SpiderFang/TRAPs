## 1. 專案在做什麼

TRAPs 是瞬態吸引剖面（Transient Attracting Profiles）。可以先把它想成海面上看不見的「吸引線」：水流會把附近漂浮物推近這條線，再沿著線帶走。

假設在水面撒下許多小葉片，水流有時會把原本分散的葉片推成細長的一排。TRAPs 分析的目的，就是從海面流速資料中，找出具有這種短期吸引作用的結構，再研究它的位置、強度、出現頻率及持續時間。

它的實際運算以瞬時表層二維流速場為基礎：計算速度梯度的對稱部分，也就是應變率張量；找出代表強壓縮的候選核心；再沿伸展方向延伸成曲線。這是由海流推導出的流動結構，不是直接量測到的垃圾濃度。

依[專案 README](../README.md)，本專案將這類分析用於貢寮、龜山島西側、新竹外海、南灣及連江五站，研究設計以 2024–2025 年 OCM 流場為基礎。五站分屬四個流場區域，貢寮與龜山島西側共用 A 區流場，站點統計仍分開。

| 希望回答的問題 | 對應的成果 |
| --- | --- |
| 此時哪些位置具有較強的短期吸引作用？ | 海流底圖上疊加 TRAP 曲線與核心。 |
| 哪些位置較常出現這類結構？ | 出現頻率、曲線通過率或核心分布地圖，註明有效資料分母。 |
| 吸引作用有多強？ | 核心吸引強度地圖及站點統計。 |
| 結構被持續追蹤了多久？ | 持續時間／觀測跨度分布及強度演化圖，處理資料缺口與截尾。 |
| 真實漂浮物是否靠近這些曲線？ | TRAP 與獨立漂流器或海廢觀測的時空對照。 |

只有模型流場時，成果應稱為「表層短期吸引潛勢」。有漂流器或海廢觀測時，才能進一步核對物體是否真的靠近。共用同一 OCM 流場的模型粒子屬於模型內部對照，不能稱為獨立漂流器驗證。

### 2.3 看吸引線能維持多久

來源：[Kunz 等（2024），圖 5](https://os.copernicus.org/articles/20/1611/2024/)。

下圖黑線代表 TRAP，青色與粉色是兩類渦旋的比較結果。

- 左圖 a：統計結構的持續時間，觀察短時間與長時間存在的結構各有多少。
- 中圖 b：呈現長時間存在的 TRAP，其吸引作用如何在生命週期中先增強、再減弱；渦旋的比較指標為邊界流速，兩者使用不同縱軸。
- 右圖 c：比較不同緯度的結構向東或向西移動速度。

（圖：Kunz 2024 圖 5：持續時間、強度演化與移動速度比較，`docs/assets/traps_concept_literature_handoff/kunz2024_fig5.png`）

圖像出處：Kunz et al.（2024），圖 5；原始 PDF 第 9 頁。僅擷取圖面，未修改圖內內容。授權為 CC BY 4.0。

對本專案而言，必須先確認跨時刻追蹤是否連續、是否有資料缺口，以及是否在研究期起訖處截尾，才能解讀持續性。首次至末次檢出的觀測跨度，不等於漂浮物的停留時間，也不一定涵蓋結構完整的物理生命週期。

### 2.4 檢查真實漂浮物是否靠近吸引線

來源：[Serra 等（2020），*Search and rescue at sea aided by hidden flow structures*，Nature Communications，圖 4](https://pmc.ncbi.nlm.nih.gov/articles/PMC7250873/)。

此研究的 2014 年實驗使用 68 個實際投放的 CODE 漂流器，透過 GPS 記錄其位置；TRAP 則由高頻雷達量測的海面流速計算。

- 白點：實際漂流器的位置。
- 紅線：計算出的 TRAP。
- 黑線：流線。
- a、b、c：不同時刻的對照，可以看到漂流器逐漸沿紅線排列。
- d：與 c 相同時刻，改用水平散度作底圖，並非另一個較晚時刻。

（圖：Serra 2020 圖 4：實測漂流器、TRAP 與不同流場底圖對照，`docs/assets/traps_concept_literature_handoff/serra2020_fig4.png`）

圖像出處：Serra et al.（2020），圖 4；原始 PDF 第 4 頁。僅擷取圖面，未修改圖內內容。授權為 CC BY 4.0。

這類成果回答「算出的吸引線，是否對實際漂浮物的短期移動有解釋能力」。它是漂流器核對，不能直接當成臺灣五站的海廢濃度觀測或驗證成果。

## 4. 本專案成果應如何表述

本專案會以五站分開的方式呈現「吸引線在哪裡、吸引有多強、多久出現一次，以及結構被持續追蹤多久」。有獨立表層觀測時，再核對漂浮物與 TRAP 的關係。

可使用的成果名稱是「表層短期吸引潛勢分析」。僅靠檢出的 TRAP 曲線，不能宣稱已量測海廢濃度、證明垃圾必定堆積、判定污染來源，或解釋海底沉積廢棄物的完整三維運動。

文獻圖型應借鏡其研究問題、分圖方式與定量比較；圖面座標、統計分母、時間尺度與數值必須由本專案資料重新計算。上述原圖應明確標為文獻成果。
